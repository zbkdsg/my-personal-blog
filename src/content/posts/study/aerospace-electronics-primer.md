## 一、领域地图

航天电子大致可以分成四条线。它们不是互斥的，实际研究里经常交叉。

| 方向 | 一句话定位 |
| --- | --- |
| 测控、通信与射频 | 解决「地面怎么看见航天器、航天器怎么把数据传回来」 |
| 航天人工智能 | 让航天器在轨自主处理信息、识别目标、辅助决策 |
| 导航与制导（GNC） | 解决「我在哪、我要去哪、怎么去」 |
| 交叉方向 | 上面三条线两两结合产生的新问题 |

## 二、航天测控、通信与射频

### 2.1 细分方向

| 细分方向 | 研究什么 | 关键词 |
| --- | --- | --- |
| 航天测控 | 地面如何监视、跟踪和控制航天器 | TT&C |
| 卫星通信 | 航天器如何高速传输数据 | Satellite Communications |
| 射频与微波 | 如何产生、接收和处理高频信号 | RF / Microwave |
| 天线技术 | 如何实现电磁波的辐射和接收 | Antenna |
| 星间通信 | 卫星之间如何建立通信链路 | Inter-Satellite Link |

### 2.2 测控不等于通信

这是初学阶段最容易混淆的一点。测控（TT&C）是三个词的缩写：

- **Telemetry（遥测）**：航天器向地面发送自身状态信息。
- **Tracking（跟踪）**：地面测定航天器的位置、速度等信息。
- **Command（遥控）**：地面向航天器发送控制指令。

也就是说，测控关心的是「状态」和「指令」，通信关心的是「数据吞吐」。两者在链路、频段和体制上有交集，但设计目标不同。

### 2.3 需要的基础课程

信号与系统、通信原理、数字信号处理、电磁场与电磁波、微波技术与天线、信息论与编码。

### 2.4 典型的科研问题

- 面向深空通信的低信噪比信号检测方法。
- 面向高速卫星通信的波束成形算法。
- 基于软件定义无线电的卫星通信系统设计。
- 星间激光通信中的捕获、跟踪与瞄准技术。
- 强干扰环境下的卫星通信抗干扰技术。
- 面向卫星互联网的多星组网与资源分配。

## 三、航天人工智能与智能信息处理

### 3.1 它要解决的问题

让航天器不仅能够获取和传输信息，还能**在轨自主处理信息、识别目标、辅助决策**。核心矛盾是：星上算力、功耗、存储都有限，而模型往往很大。

### 3.2 细分方向

| 细分方向 | 研究内容 |
| --- | --- |
| 星载图像处理 | 对遥感、光学等图像进行处理 |
| 智能目标识别 | 利用深度学习识别空间或地面目标 |
| 星载智能计算 | 在有限算力和功耗条件下部署 AI 模型 |
| 自主任务规划 | 让航天器自主安排观测和执行任务 |
| 多源信息融合 | 融合不同传感器的数据 |

### 3.3 三个研究热点

**星载边缘计算（On-board Edge Computing）**
如何让 AI 模型真正跑在星载计算平台上，而不是只在地面验证。

**多源信息融合（Multi-sensor Data Fusion）**
航天器可能同时装有星敏感器、陀螺仪、GNSS 接收机、光学相机等设备。不同传感器提供的信息各自带有误差和不确定性，如何融合这些信息得到更准确的状态估计，是一个重要方向。

**航天器自主决策（Autonomous Spacecraft）**
希望航天器能根据自身状态和外部环境，独立完成一部分任务规划和决策。

### 3.4 需要的基础课程

Python 编程、线性代数与概率统计、数字信号处理、机器学习、深度学习、最优化理论；如果偏硬件部署，还需要 FPGA 与嵌入式系统。

> **公式待补充**：多源融合中的状态估计与信息矩阵形式。

## 四、航天器导航与制导

### 4.1 GNC 是什么

GNC = Guidance, Navigation and Control，即制导、导航与控制。三个词对应三个问题：

- **导航**：我现在在哪、姿态如何。
- **制导**：我要去的目标在哪，路径怎么规划。
- **控制**：怎么让执行机构按规划去动作。

### 4.2 一个例子：卫星自主变轨

- 导航：确定卫星当前轨道状态。
- 制导：计算从当前轨道到目标轨道的变轨方案。
- 控制：控制推进系统执行变轨。

这个例子把三个环节串起来了，也说明了为什么三门课要一起学：轨道力学给「在哪」，最优控制给「怎么去」，执行机构与控制器给「怎么动」。

### 4.3 导航的研究方向

| 研究方向 | 研究内容 |
| --- | --- |
| 卫星轨道确定 | 确定卫星在空间中的位置和速度 |
| 姿态确定 | 确定卫星当前朝向 |
| 惯性导航 | 利用陀螺仪、加速度计推算运动状态 |
| GNSS 导航 | 利用卫星导航系统进行定位 |
| 组合导航 | 融合 GNSS、惯性导航等多种信息 |

值得重点关注的方向：GNSS/INS 组合导航、深空自主导航、基于视觉的航天器相对导航、星间相对导航、多传感器融合，以及基于人工智能的导航与状态估计。

### 4.4 制导的研究方向

- 轨迹规划
- 最优制导
- 自主交会与对接
- 编队飞行控制
- 空间避碰与碰撞规避

### 4.5 需要的基础课程

理论力学、自动控制原理、现代控制理论、轨道力学与航天器动力学、线性代数与概率统计、最优化理论、卡尔曼滤波与状态估计。

> **公式待补充**：卡尔曼滤波的预测与更新方程（状态方程、观测方程、增益、协方差更新）。

> **图片待补充**：GNC 闭环框图（导航 → 制导 → 控制 → 动力学 → 敏感器）。

## 五、交叉方向

| 交叉方向 | 研究思路 |
| --- | --- |
| GNSS + 机器学习 | 用机器学习改善卫星导航信号处理、定位误差建模、复杂环境下的定位性能 |
| 视觉导航 + 深度学习 | 识别目标、提取特征，估计相对位置与姿态 |
| 通信感知一体化（ISAC） | 让通信系统同时承担感知任务，探索通信、测距、定位和环境感知的融合 |
| 星间通信 + 自主协同导航 | 利用星间测距、通信链路和多星信息，实现编队协同定位与协同任务 |
| 强化学习 + 自主制导 | 用强化学习研究轨迹规划、自主交会、避碰和复杂任务决策 |

交叉方向的价值在于：单条线的成熟度已经较高，新的问题往往出现在两条线的接缝处。
